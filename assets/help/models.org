#+title: Choosing a model
#+STARTUP: showall

Checked: 2026-10-27

The model lists in the settings show the current prices where the provider sends them.

"Cheap", "medium" and "expensive" are rough price classes for a purpose,
not a quote. Long notes, many tool calls, image size and quality change
the cost. Choose the chat and image providers separately under
[[id:roam-graph-help-settings][Settings]].

* Quick start: three setups
In the model lists in AI settings, a recommended model carries the label
"Recommended" with its purpose and price class, and the "Recommended"
chip shows only those. Pick one of these three setups to start. The
chat's provider and model are set in AI settings (AI → Chat); the image settings are *Images with:* and *Infographics with:* (AI → Images).

- *Cheap:* Chat on Vercel AI Gateway with ~deepseek/deepseek-v4-pro~
  (cheap), for questions and for the agent; it calls tools. *Images
  with:* Vercel AI Gateway, ~openai/gpt-image-1-mini~ (cheap), for
  plain illustrations. For exact charts the agent uses ~create_chart~, which
  draws them offline and costs no image model.
- *EU:* Chat on Mistral with ~mistral-large-4~ (cheap), for
  questions and the agent. *Images with:* Mistral, ~mistral-medium-latest~
  (medium), for illustrations. *Infographics with:* Vercel AI Gateway with
  "EU only" on and ~google/gemini-2.5-flash-image~ (medium).
- *Best quality:* Chat on Anthropic with ~claude-sonnet-5-5~
  (medium), for questions and the agent; ~claude-opus-5-5~ (expensive),
  for hard work. *Images with:* and *Infographics with:* Vercel AI
  Gateway with ~openai/gpt-image-2~ (expensive); Anthropic makes no images
  in the app.

The sections below list more models for each purpose.

* Charts and infographics
Both give a picture with numbers, but they work differently.

- ~create_chart~ draws a line, bar or area chart from the exact values the
  agent gives it. It runs on the device, needs no image model, and every
  value in the picture is the one given. Use it for data such as interest
  rates, prices or time series.
- An infographic model paints a designed picture: layout, icons, text and
  colour. It can get a number or a word wrong, so check what it wrote.
  Use it when the look matters more than exact values.

* Chat questions about the notes
Even a question needs tool calls: the model searches and reads the notes.
Start with one of these; use a stronger model for difficult comparisons.

- *Claude on AWS Bedrock (EU):* ~eu.anthropic.claude-sonnet-5-5~ (medium),
  for questions across several notes.
- *Mistral:* ~mistral-large-4~ (cheap), a general choice with EU
  processing; it is in public preview.
- *Scaleway:* ~qwen3.6-35b-a3b~ (cheap), for straightforward questions.
- *Vercel AI Gateway:* ~deepseek/deepseek-v4-pro~ (cheap), for general
  questions outside the EU; ~anthropic/claude-sonnet-5.5~ (medium), for
  harder comparisons or with "EU only" on.
- *Anthropic:* ~claude-sonnet-5-5~ (medium), for general questions;
  ~claude-opus-5-5~ (expensive), for difficult reasoning.
- *DeepSeek:* ~deepseek-v4-pro~ (cheap), if processing in China is suitable.
- *Qwen:* ~qwen3.8-max~ (medium), for general questions; the preset uses
  Singapore.
- *OpenRouter:* ~deepseek/deepseek-v4-pro~ (cheap), the default, for
  general questions; ~anthropic/claude-sonnet-5.5~ (medium), the strong
  model, for comparisons across notes. The chosen host's terms apply.
- *Hugging Face:* ~Qwen/Qwen3-Coder-480B-A35B-Instruct~ (medium), for
  questions that need tools; check which host serves it.
- *Custom:* there is no fixed model or price class. Use the server's list
  and documentation; a chat model must support tools.

* Edits by the agent
Tool calls must work reliably: the agent reads first and then calls the
editing tools. For a large change, ask it to explain the plan first.

- *Claude on AWS Bedrock (EU):* ~eu.anthropic.claude-sonnet-5-5~ (medium);
  ~eu.anthropic.claude-opus-5-5~ (expensive) for difficult changes.
- *Mistral:* ~mistral-large-4~ (cheap), for edits with EU processing.
- *Scaleway:* ~qwen3.6-35b-a3b~ (cheap), documented with function calling
  and parallel tool calls; start with a small edit.
- *Vercel AI Gateway:* ~anthropic/claude-sonnet-5.5~ (medium), for changes
  across notes, also with "EU only"; ~deepseek/deepseek-v4-pro~ (cheap),
  for simpler edits outside the EU.
- *Anthropic:* ~claude-sonnet-5-5~ (medium), a starting choice for tool
  calls; ~claude-opus-5-5~ (expensive), for complex changes.
- *DeepSeek:* ~deepseek-v4-pro~ (cheap), for simpler changes, processed
  and stored in China.
- *Qwen:* ~qwen3.8-max~ (medium), for edits through its tools.
- *OpenRouter:* ~anthropic/claude-sonnet-5.5~ (medium); or
  ~deepseek/deepseek-v4-pro~ (cheap) for simpler edits. Choose a route
  that supports tools.
- *Hugging Face:* ~Qwen/Qwen3-Coder-480B-A35B-Instruct~ (medium), for
  agent tasks; tool support depends on the host too.
- *Custom:* choose a model documented to call tools. Its price class
  depends on the server; try a small change in review mode first.

* Images
The image model is separate from the chat model. For an image based on
the notes, ask the chat in agent mode; for a picture from a description,
use "Create image" in the note's edit menu.

An infographic (text, numbers, labels) can use another provider and model
than an illustration: set *Infographics with:* in AI settings (AI → Images → Infographics with:). The same
model picker, with its prices, chooses both. GPT Image
(~openai/gpt-image-2~) and Gemini Image (~google/gemini-2.5-flash-image~)
set text well; FLUX and Mistral's image tool, which uses FLUX, do not. A
good pair: Mistral for illustrations, Vercel with ~openai/gpt-image-2~ for
infographics.

- *Mistral image tool:* ~mistral-medium-latest~ (medium). A good choice
  for an illustration with EU processing. The app makes a Mistral agent
  with the image tool and uses its Conversations API; this is not the
  Images API.
- *Vercel Images API:* ~openai/gpt-image-2~ (expensive), for detailed
  illustrations and images with text. Use the "Images API" setting;
  the preset has no EU route for it.
- *Vercel chat with image output:* ~google/gemini-2.5-flash-image~
  (medium), for quick illustrations. Use "Chat with image output". This
  is the preset for images with "EU only" on.
- *DashScope Qwen Image:* ~qwen-image-2.0~ (cheap), for straightforward
  illustrations through Qwen's own image API. The preset uses Singapore;
  the key must belong to that region.
- *OpenRouter Images API:* ~google/gemini-2.5-flash-image~ (medium), the
  preset's image model, for quick illustrations and images with text. The
  selected host's terms apply. OpenRouter does not list GPT Image.
- *Custom:* use an image model and API documented by that server. There
  is no fixed model or price class.

The app has no image path for the Bedrock, Anthropic, DeepSeek, Scaleway
or Hugging Face presets. An image understood as input is not image output.

The image picker shows a price per image when supplied, "from" for size,
quality or style choices, or token prices when that is all the list gives.
Otherwise it says "price not in the provider's list". "Price (lowest
first)" orders per-image prices first, then token prices by output price,
and unknown prices last. A token price cannot be compared with a price
per image; this does not tell what an actual request will cost.

* Speech to text
Voice memos (up to 30 minutes) are transcribed by a separate model, set in
AI settings → Speech to text.

- *Mistral ~voxtral-mini-latest~* (cheap): about 0.003 USD per minute of
  audio, processed in the EU, can label speakers. The default when a
  Mistral key is set; it uses the key of Mistral under Chat.
- *OpenAI ~gpt-4o-mini-transcribe~* (cheap): about 0.003 USD per minute,
  processed outside the EU, at most 25 MB per recording, no speaker
  labels in the app. ~whisper-1~ also works. It has its own key field.

A recording of 10 minutes costs about 3 cents. The model list of the chat
does not include these models.

* EU only
These statements follow the provider notes in the app's settings.

- *Mistral:* ~mistral-large-4~ (cheap) for chat and edits,
  ~mistral-medium-latest~ (medium) for the image tool. EU company and EU
  processing; no training on paid use; abuse logs kept for thirty days.
- *Scaleway:* ~qwen3.6-35b-a3b~ (cheap) for chat and edits. French
  company, EU processing, prompts not kept by default; open models only.
- *Claude on AWS Bedrock (EU):* ~eu.anthropic.claude-sonnet-5-5~ (medium)
  or ~eu.anthropic.claude-opus-5-5~ (expensive). Use the EU inference
  profiles; AWS is a US company subject to the CLOUD Act.
- *Vercel AI Gateway:* turn "EU only" on. Use
  ~anthropic/claude-sonnet-5.5~ (medium) for chat and edits, or
  ~google/gemini-2.5-flash-image~ (medium) for images. Inference and stored
  data stay in the EU for models with an EU route; others fail. Vercel
  is a US company. DeepSeek V4 Pro and the Mistral model on Vercel have
  no EU route in the preset notes.

Anthropic directly processes globally or in the US; DeepSeek processes
and stores in China; the Qwen preset uses Singapore. OpenRouter's note
says EU-only routing needs its Business plan; this app's preset does not
enforce that route. Hugging Face and Custom do not guarantee a region.
Use one of the EU options above when the notes must stay in the EU.

* OpenRouter: how to find a model
OpenRouter lists hundreds of models. To find one that works here:

1. Open the model list of the chat and turn on the "Calls tools" chip.
   The chat needs a model that calls tools to read and change notes.
2. Order the list by price (lowest first).
3. Start with a recommended model: they come first and carry the label.
   The preset starts with ~deepseek/deepseek-v4-pro~ (cheap) and has
   ~anthropic/claude-sonnet-5.5~ (medium) as the strong model.
4. Remember that the host OpenRouter chooses for the model sets the
   terms for your data, and that OpenRouter adds a fee of 5.5 % to credits.

Images go through the Images API; the preset uses
~google/gemini-2.5-flash-image~ (medium). The image list also has the
price order.

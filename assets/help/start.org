#+title: Roam Graph help
#+STARTUP: showall

Roam Graph shows my org-roam notes on the phone, the tablet and the
notebook, without Emacs. Syncthing copies the notes from the laptop; the
app reads the folder, builds the same graph org-roam builds, and draws it.

The app can create, edit and delete notes. Every write checks the file
version first, and old texts are kept so changes can be undone.

#+title: The node view
#+STARTUP: showall

Shows a note as formatted Org: a whole file, or a heading with its subtree.

- *Links*: an ~id:~ link opens the linked note on a new page; Back
  returns. Other links are shown but not opened.
- *Links* and *Backlinks*: below the text, this note's ~id:~ links, and
  every link to this note, with where in the linking note it is.
- *Trash icons* remove a link: on a link, from this note; on a backlink,
  from the other note. The link becomes its text, so nothing is lost. On an
  image, the image link goes with its ~#+caption:~ and ~# image prompt:~
  lines; the image file stays in the folder. Each shows the change first,
  and is saved as every edit, with the old version kept.
- *+* adds a link: next to *Links*, to the note you choose, on this
  note's "See also:" line; next to *Backlinks*, to this note, on the
  chosen note's "See also:" line. Type a title that is no note's, and the
  list offers a *New note* with it first, as Emacs's org-roam-node-insert
  does; it is made at once and the link goes to it. The change shows
  first, and is saved as every edit.
- *Insert link* in *Edit text* puts a link to a note you choose at the
  cursor; selected text becomes the link's description.
- Changes made in Emacs show within about 30 seconds while the app is
  open, once Syncthing has brought them.
- *Sections* open collapsed or expanded, as set in
  [[id:roam-graph-help-settings][Settings]]; a note's own ~#+STARTUP:~
  line comes first. Tap a heading to open or close it.
- *Images* from the notes folder show at their Org width; tap one to zoom.
  SVG is drawn too. Web images stay links: the app reads only the folder.
- *LaTeX* formulas are rendered; ~\[ \]~ and ~$$ $$~ on their own line.
- *Mermaid* blocks show the image Emacs made; a block without one is drawn
  on the device, marked as such.
- *Source blocks* are coloured as Emacs colours them.
- *Open in Orgro* hands the file to Orgro, to read or edit it there.
- *Show in graph* returns to the graph, centred on this note.
- *New node from here* writes a new note linking to this one; see
  [[id:roam-graph-help-capture][Capture]].
- The *AI* menu: see [[id:roam-graph-help-ai][AI]].

#+title: Capture and shared text
#+STARTUP: showall

* A new node
The *New node* button (+) in the graph, or *New node from here* in a note,
writes a new note as org-roam's capture does on the laptop: a file
~roam/<date and time>-<title>.org~ with a new ~:ID:~, ~#+title:~ and
~#+filetags:~. Syncthing brings it to the laptop, where org-roam finds it.

The tags are chosen as in *Title, tags and aliases*: tap the graph's tags
below the field, or type one and add it with space, comma, colon or Enter;
a tag no note has yet shows as *New tag*.

From a note, the new note can link to it. The link is in the new file, so
the old note gets a backlink and is never changed.

* Shared text
Text shared to Roam Graph from another app, such as an AI app, opens the
same capture screen, with a title and text proposed from it. Nothing is
written until I save (the check mark).

Instead of a new node, the shared text can be used in other ways: tap
*Other uses of the text* in the bar of the capture screen, then
- *Add to a node*: the text goes to the end of the node you choose.
- *Replace a node's text*: shown as a diff first.
- *Ask AI*: a new chat opens with the text in the message field, as a
  block that starts with ~Shared text:~. Nothing is sent before I send it;
  I can write my question below the block first.
- *Add to a chat…*: the list of chats opens; the chat I choose (or a new
  chat) gets the text in its message field in the same way.
- *Import as a note as it is*: only for one ~.org~ file, see below.
The capture screen closes and the original shared text is used, so choose
this before you edit the text there; edit it on the next screen.

* Shared text files
Files shared from a file manager or another app are read as text: files
ending in ~.txt~, ~.md~, ~.markdown~ or ~.org~, or sent as text. At most 20
files at a time and 1 MB per file; other files are not taken, and a message
names them. A file that is not UTF-8 is read as Latin-1, with a note above
the fields.

- *One file* opens the capture screen like shared text. Its first line is
  the title when it is a title line (~#+title:~, an Org heading ~* ...~ or a
  Markdown heading ~# ...~); otherwise the title is the file name without
  its ending. The tags of an Org file (~#+filetags:~) are proposed too.
- *Several files* ask first: *One note per file* opens one capture screen
  after the other, or *One note* puts all files in one note, each under a
  heading with its file name.
- *Import as a note as it is* (one ~.org~ file) copies the file into
  ~roam/~ with its name, unchanged. A file without an ~:ID:~ gets one at the
  top, so org-roam takes it as a node. A file of that name that is already
  there is never replaced; the import then stops with a message.

* Voice memos
A voice memo shared from a recorder app or a messenger (MP3, M4A/AAC, WAV,
FLAC, OGG/Opus or WebM) is turned into text and opens the capture screen.
Live dictation is not part of this: the keyboard's microphone works in
every text field.

- *Set up once:* AI → Speech to text. Mistral (Voxtral, about 0.003 USD per
  minute, processed in the EU) is the default when a Mistral key is set;
  OpenAI is the other choice and has its own key field there. The model,
  the language and the speaker labels are set there too.
- *The first time* for a provider, a question says where the recording
  goes and that the provider gets the recording itself. The recording is
  sent only after I agree, and only for the file I shared.
- *While it works* a screen shows the file name, its length and *Cancel*.
  I can leave the app: Android keeps it going with an ongoing notification
  and shows *Voice memo ready* when the text is there.
- *Review:* the text opens in the capture screen, editable. The title is
  proposed as ~Voice memo 2026-11-01 09:14~, and the first line of the text
  says ~Transcribed from <file> (<length>) with <provider> <model>.~ Nothing
  is saved before I save. The other uses of the text work as for shared
  text: add to a node, Ask AI, add to a chat.
- *Keep the recording with the note* (off by default) copies the audio file
  next to the note in ~roam/~, named like the note, and links it with a
  ~file:~ link. Without it the audio is not copied into the notes.
- *Speakers* (AI → Speech to text, Mistral only) labels the text
  ~Speaker 1:~, ~Speaker 2:~. With labels Mistral is not given a language.
- *At most 30 minutes*, sent whole in one request, and at most 25 MB for
  OpenAI. A longer recording is refused with its length. The length is
  read from the file; if the app cannot read it from a file, only the size
  is checked (at most 100 MB), and the provider charges for what it gets. Transcribe
  meetings and talks on the computer, for example with Whisper, and share
  the text as a text file.
- *An error* from the provider is shown in plain words with *Try again*.
  Without a key the message names AI → Speech to text.

* On the desktop
- Drop text or text files on the window: they open the capture screen as
  above. Dropped on a chat, they go into its message field instead.
- *New note from clipboard* in the graph's *More* menu, or Ctrl+Shift+V
  (Cmd+Shift+V on macOS): the text on the clipboard opens the capture
  screen.
- *Open files…* in the graph's *More* menu chooses text files and voice
  memos to bring in. Audio files dropped on the window are transcribed as
  above.

* The first time
Android may let the app only read the folder. Saving then asks to choose
the folder again and allow writing.

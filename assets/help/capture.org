#+title: Capture and shared text
#+STARTUP: showall

* A new node
The *New node* button (+) in the graph, or *New node from here* in a note,
writes a new note as org-roam's capture does on the laptop: a file
~roam/<date and time>-<title>.org~ with a new ~:ID:~, ~#+title:~ and
~#+filetags:~. Syncthing brings it to the laptop, where org-roam finds it.

The tags are chosen as in *Title, tags and aliases*: tap the graph's tags
below the field, or type one and add it with space, comma, colon or Enter;
a tag no note has yet shows as *New tag*.

From a note, the new note can link to it. The link is in the new file, so
the old note gets a backlink and is never changed.

* Shared text
Text shared to Roam Graph from another app, such as an AI app, opens the
same capture screen, with a title and text proposed from it. Nothing is
written until I save (the check mark). Text cannot be shared into the app
on the desktop.

Instead of a new node, the shared text can go into an existing one: tap
*Use for an existing node* in the bar of the capture screen, then *Add to a
node* (the text goes to the end of the node you choose) or *Replace a
node's text* (shown as a diff first).

* The first time
Android may let the app only read the folder. Saving then asks to choose
the folder again and allow writing.

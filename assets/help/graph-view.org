#+title: The graph view
#+STARTUP: showall

Each dot is a node: a note, or a heading with an ID. A line is an ~id:~
link; the arrow points to the linked note. Other links (web, files) are not
drawn, as in ~org-roam-graph~.

- *Tap* a node to select it and open it. On a tablet held sideways the
  note opens beside the graph; otherwise on its own page.
- *Long press* a node, or *right click* on the desktop, for *Open*, *Edit*
  and *Delete…*. This opens a menu; it never deletes a note directly. For
  the steps of *Delete…* see
  [[id:roam-graph-help-delete-note][Delete a note]].
- *On a tablet held sideways*, drag the divider between graph and note to
  share the width, double-tap it for 40 : 60 again, or fold the graph away
  with its arrow button. The app remembers the layout.
- *Open node* (the page icon in the bar, on a screen that shows one thing
  at a time) opens the selected node.
- *Pinch and drag* to zoom and move. Titles show once they are large enough
  to read.
- *Search* (the magnifier) finds notes by title, alias and tag; see
  [[id:roam-graph-help-search][Search and selected notes]].
- *New node* (the plus button) writes a new note; see
  [[id:roam-graph-help-capture][Capture and shared text]].

* Show
The "Show" menu (the hub icon) chooses which part of the graph is drawn:
- *Whole graph*: every node.
- *Connected part*: the nodes the selected node reaches through links, in
  either direction.
- *Neighbourhood: 1, 2 or 3 steps*: the nodes that many links away from the
  selected node. A small part is faster to draw and easier to read.

* View
The "View" menu (the chart icon) holds everything that changes how the
graph looks, in two groups; a check mark shows the current choice.
- *Layout*: *Circular*, *Force-directed*, *Radial*, *Grouped by
  communities* or *Hierarchical (dot)*, where the dots go; see
  [[id:roam-graph-help-layouts][Layouts]].
- *View*: colours or sizes the nodes by a graph algorithm; see
  [[id:roam-graph-help-views][Graph views]].
- *About the layouts* and *About the views*: those help pages.

* More
- *Centre*: moves the selected node to the middle. In the radial layout,
  the rings are drawn again around it.
- *Ask AI*: see [[id:roam-graph-help-ai][AI]].
- *Recent changes*: hand deletes and AI changes, with one *Undo these
  changes* for each action, also after its message has gone. Newer texts
  stay unchanged; notes that could not be restored are named. It shows
  when the app can write to the folder.
- *Folder and index*: see below.
- *Settings*: see [[id:roam-graph-help-settings][Settings]].
- *Help*: these pages, starting with the list of tasks.

* Folder and index
:PROPERTIES:
:ID:       roam-graph-help-folder-index
:END:
The app opens the graph at once when the folder is known. *More*, then
*Folder and index* opens a sheet with what the last scan found: the counts
to compare with org-roam, the files org-roam skips, the unreadable files and
the Syncthing conflict copies. It also has the folder's name and three
buttons:
- *Scan again*: reads the files that changed. The graph shows the result.
- *Rebuild index*: reads every file again.
- *Change folder*: picks another org folder.

When the scan found problems, a warning icon is in the top bar; its tooltip
says how many problems there are. It opens the same sheet. Without problems there is no
icon. If the folder cannot be read (access lost, no ~roam/~ folder, a failed
scan), the app shows its first page again, with the reason.

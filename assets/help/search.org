#+title: Search and selected notes
#+STARTUP: showall

Open *Search* with the magnifier in the graph or note view. Type a title
or alias, or choose tags. *In the text* searches the words inside notes.
Tap a result to open it. In the results for titles, aliases and tags,
*Show in graph* shows it in the graph; for a result *In the text*, open it
first and use *Show in graph* in the note. To search
inside the note that is open, see
[[id:roam-graph-help-search-in-note][Search inside a note]].

* Selected notes
Long press a result to select it. While a selection is active, taps add
or remove notes. *Share with AI* shares the selected notes, respecting
hidden tags.

*Set language…* asks for a language code (such as ~de~ or ~en~) and
adds or replaces ~#+language:~ in each selected note's file. A heading
has no language of its own, so its file is changed; the dialog says
which files. One *Undo* in the message restores all of them. See
[[id:roam-graph-help-note-language][The language of notes]].

*Delete…* deletes the selected notes after confirmation; the steps and
the choice about links are those of
[[id:roam-graph-help-delete-note][Delete a note]]. The dialog lists up to
ten names, then says how many more, and asks once for all notes. Links
between notes that are both deleted need no changes. Notes hidden from AI
may be deleted by hand too.

One *Undo* in the message brings back the whole action, including changed
links. The message stays until another action or a swipe. Later, use
*Recent changes* in the graph's *More* menu.

See [[id:roam-graph-help-node-view][The node view]] and
[[id:roam-graph-help-graph-view][The graph view]].

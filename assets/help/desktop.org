#+title: The desktop app
#+STARTUP: showall

The notebook has the same app as the phone: the graph, layouts, search, the
node view, the AI and the edits are the same. It runs on Linux, Windows
and macOS, and reads the same notes folder as Emacs. This page lists what
differs from the phone. Installing: see
[[id:roam-graph-help-install][Install and update the app]].

* Install
Each full release has one file for each system. A pre-release has the
APK only.
- *Linux*: ~roam-graph-<version>-linux-x64.tar.gz~. Unpack it, then run
  ~bundle/install.sh~. It adds *Roam Graph* to the app menu. To update, run
  ~${XDG_DATA_HOME:-$HOME/.local/share}/roam-graph/app/install.sh --update~;
  to remove the app, run the same file with ~--remove~. Your notes,
  settings and keys stay.
- *Windows*: ~roam-graph-<version>-windows-x64.zip~. Unpack it, then start
  ~roam_graph_mobile.exe~. The app is not signed: if SmartScreen warns,
  choose *More info*, then *Run anyway*.
- *macOS*: ~roam-graph-<version>-macos.zip~. Move *Roam Graph* to
  Applications. The app is not signed: the first time, try to open it; macOS
  refuses. Then open System Settings, Privacy & Security, and choose *Open
  Anyway* for Roam Graph.

* First start
Tap *Choose org folder* and pick the folder that holds ~roam/~ (or ~roam/~
itself). The app remembers it; *Change folder* in *More*, *Folder and index* picks
another. From then on the app opens the graph at once. The app edits
the same files as Emacs. Emacs reloads a changed file with
~global-auto-revert-mode~, else it asks.

* Open in Emacs
The note's button is *Open in Emacs* instead of *Open in another app…*. It runs
~emacsclient~ at the note's heading, so Emacs needs ~(server-start)~;
without a running server, Emacs itself starts. If the app cannot start
the command at all, it says so and names *Settings*; it does not see a
later failure of Emacs itself.

The command is *Emacs command* in [[id:roam-graph-help-settings][Settings]]
(shown on the desktop only). On Windows the default is ~emacsclientw.exe~;
if Emacs is not on the ~PATH~, enter the full path. On macOS an app started
from the Dock does not see the shell's ~PATH~, so enter the full path, for
example ~/opt/homebrew/bin/emacsclient~.

* Other differences
- Search inside a note: Ctrl+F (Cmd+F on macOS); Escape closes it. See
  [[id:roam-graph-help-search-in-note][Search inside a note]].
- In the graph, *right click* on a node opens the menu that a long press
  opens on a phone.
- In a note, *right click* on a heading opens its menu, with the keys.
  Click a heading to make it the current one (it is lightly marked); then:
  Alt+Shift+Left promotes it, Alt+Shift+Right demotes it, Alt+Up and
  Alt+Down move it, Shift+Left and Shift+Right change its TODO state,
  Delete deletes it, and Ctrl+Z (Cmd+Z on macOS) undoes the last change.
  The keys do nothing while the search field has the cursor. Swipes on
  headings are off on the desktop; turn on *Swipe actions on headings* in
  Settings → View to drag a heading with the mouse.
- Web links open in the web browser.
- *Share with AI* copies the text to the clipboard.
- Instead of sharing text into the app: drop text or text files on the
  window (or on a chat), *New note from clipboard* (Ctrl+Shift+V, Cmd+Shift+V
  on macOS) or *Open files…* in the graph's *More* menu. See
  [[id:roam-graph-help-capture][Capture and shared text]].
- On Linux, API keys are kept in the system keyring.

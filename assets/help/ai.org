#+title: AI: sharing, hidden notes and the chat
#+STARTUP: showall

* Hidden from AI
Notes with a tag such as ~:private:~ are never shown to an AI: not in a
share, not to the chat. Headings with such a tag are left out of the notes
that are. Set the tags in [[id:roam-graph-help-settings][Settings]], under
AI.

* Sharing with an AI app
*Share with AI* (a note's AI menu, or several notes selected in search
with a long press) sends the notes with their texts and links.
An AI app's answer can come back as a new note: share it to Roam Graph
([[id:roam-graph-help-capture][Capture and shared text]]).

* Images
*Create image* (a note's edit menu) asks an image model for a picture of
what I describe; the image is added to the note only when I tap "Add to
the note". Only the description and, if ticked, the note's title are sent.

The provider is set under *Images with:* in AI settings: the chat's
provider by default, or another one with its own key, image model and "EU
only". Vercel AI Gateway, OpenRouter, Qwen, Mistral and Custom make images.
Mistral makes them with its built-in image tool, in the EU; the app
downloads them only from Mistral's servers.

Above "Make image" a line says which provider and model make the image,
and whether that is in the EU, outside it, or not known. With "EU only" on,
Vercel uses Gemini 2.5 Flash Image, the one image model there with an EU
route. When a model has no EU route, *Make this one outside the EU* makes
this one image without the EU option; "EU only" stays on.

** Images in the chat
For an image about the contents of the notes, such as an infographic, ask
in the chat, in agent mode: "Make an infographic of my training over the
last 5 years for this note". The AI reads the notes first, writes the
image prompt with the facts in it, and adds the image with a caption to
the note, below its text, with the prompt as a comment (~# image
prompt: …~). The image shows in the chat; the AI is shown it too, if its
model can see images, and checks it. The chat knows today's date.

By default the AI makes one image per message; set *Most images the agent
may make for one message* in AI settings. A second image for the same note
in one message replaces the first. "Undo all changes of this message"
takes the image out of the note; the image file stays in the image folder.

* The AI chat
*Ask AI* (the graph's "More" menu, or a note's AI menu) opens a chat. The
AI reads the notes itself, with the tools of my org-roam MCP server:
search, read, backlinks, paths and the
[[id:roam-graph-help-algorithms][graph algorithms]]. The tool calls show in
the chat; ~id:~ links in answers open the note; "Save as new node" turns an
answer into a note after I review it.

The chat needs a provider and a key, set under AI in
[[id:roam-graph-help-settings][Settings]]. The app goes online only for the
chat, and only when I send a message: my message and the notes the AI
reads go to that provider. Each provider's note says where the data goes;
some keep it in the EU. Where the provider has a stronger model, the chat
can switch to it.

** Web access
With *Web access for the AI* on (AI settings, under "Web"; off by
default), the chat can also use the web, for questions the notes do not
answer:
- *fetch_web_page* reads a web page, with every provider. The page is
  fetched from the phone: only ~https://~ addresses, never an address in
  the own network (the phone itself, the router, other devices at home;
  also not after a redirect), without cookies or logins, at most 20
  seconds and about 100,000 characters of text.
- *web_search* is Anthropic's own search: the search words go to
  Anthropic, which searches and reads the results. Mistral has a web
  search only in another API than the one the chat uses, and Claude on
  Amazon Bedrock has none; there the AI only reads pages whose address it
  knows.

Searches and pages together are at most *Most web searches for one
message* (5 by default). The AI names its sources as links, also in the
notes it writes from facts of the web. Notes hidden from AI stay hidden:
the AI does not see them, so it cannot put them into a search.

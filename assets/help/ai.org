#+title: AI: the chat and the agent
#+STARTUP: showall

The AI features are: a chat that reads my notes, an agent that can change
them, and images. This page is about the chat and the agent. See also:
- [[id:roam-graph-help-images][AI images, infographics and charts]]
- [[id:roam-graph-help-ai-privacy][AI privacy: hidden notes and web access]]
- [[id:roam-graph-help-models][Choosing a model]], for suggestions by purpose and price class.

* Ask the AI
:PROPERTIES:
:ID:       roam-graph-help-ask-ai
:END:
1. Choose a provider and enter its key: *AI settings* (the gear on the
   first screen and in the chat), or *Settings*, *AI* in the graph's
   *More* menu. Open *Chat*, then go back and tap the check mark to save. See
   [[id:roam-graph-help-settings][Settings]].
2. Open the chat: *Ask AI* in the graph's *More* menu, or in a note's *AI*
   menu (the sparkle icon). From a note, the chat starts with that note.
3. Type the question and send it.

The AI reads the notes itself, with the tools of my org-roam MCP server:
search, read, backlinks, paths and the
[[id:roam-graph-help-algorithms][graph algorithms]]. The tool calls show in
the chat; ~id:~ links in answers open the note.

In the bar of the chat:
- *Model* (the sliders icon) switches between the default model and the
  strong model. It shows only when *Strong model (optional)* is set to a
  different model in AI settings (AI → Chat).
- *Recent AI changes* shows what the AI changed.
- *New chat* starts again.
- *AI settings* opens the settings.

The chat goes online only when I send a message: my message and the notes
the AI reads go to the chat provider. Each provider's note says where the
data goes; some keep it in the EU. Notes with a hidden tag stay out. What
else leaves the phone (images, edits, web access) is on
[[id:roam-graph-help-ai-privacy][AI privacy]].

** Share notes with an AI app
*Share with AI* (a note's *AI* menu, or several notes selected in search
with a long press) sends the notes with their texts and links to another
AI app. On the desktop it copies the text to the clipboard.
An AI app's answer can come back as a new note: share it to Roam Graph
([[id:roam-graph-help-capture][Capture and shared text]]).

* Let the AI edit notes
:PROPERTIES:
:ID:       roam-graph-help-ai-edit
:END:
*Let the AI change notes* in AI settings (AI → Agent and limits) has three
choices:
- *Off: the AI only reads.*
- *Review each change first*: the AI proposes a change and the chat shows
  it with *Review*. Nothing is saved before I save it there.
- *Agent: it changes notes itself, I can undo*: the AI creates, edits and
  links notes itself. A summary under the answer lists each note, to open
  or to see the change as a diff.

To undo an agent's changes, tap *Undo all changes of this message* in the
summary. *Recent changes* in the graph's *More* menu, or *Recent AI changes*
in the chat, keeps the same history, also after the message has gone; it
has one *Undo these changes* for each action. Newer texts stay unchanged
and notes that could not be restored are named.

The limits are in AI settings, under AI → Agent and limits: *Most changes the agent may make for one
message*, *Most images the agent may make for one message* and *Most notes
one AI change set may edit*. For a large change, ask the agent to explain
its plan first.

To change one note, or a note and its linked notes, without the chat, use
*Edit with AI* in the note's *Edit* menu (⋮):
1. Write what the AI should change, and tick *Also the linked notes* if it
   should change them too.
2. Tap *Ask the AI*.
3. With linked notes, the AI first shows its plan. Tap *Go ahead* to
   continue or *Back* to change the instruction.
4. Look at the diff of each note, and save only what is right. The old
   versions are kept.

** Save an answer as a note
*Save as new node* under an answer lets the AI make a note of it: a short,
fitting title in the language of the answer, the content as Org text
without chat phrases, and links to the notes the answer used and to the
note the chat was opened from.
- In agent mode, the button sends that request as my message; the AI makes
  the note itself, and it shows in the summary with *Undo all changes of
  this message* and in *Recent changes*.
- In review and off mode, the AI is asked once more, without tools, for the
  title and text; *New node* opens filled in with them, and nothing is
  saved before I save there. If its answer cannot be read, the first line
  of the answer is the title, as for shared text.

* The language of notes
:PROPERTIES:
:ID:       roam-graph-help-note-language
:END:
The AI writes a new note in one language and marks it with Org's
~#+language:~ line after ~#+title:~. The language is, in this order:
1. the one my request asks for ("auf Deutsch", "in English");
2. the ~#+language:~ of the note the chat starts from;
3. the language most of that note's links and backlinks have, when at
   least 2 have one and one value has more than half;
4. *Language of new notes* in AI settings (AI → Notes; ~en~ by
   default). To change it, type a language code, or tap one of the
   language chips below the field.

Example: the chat is opened from "Pilzsuche", which has ~#+language: de~.
The AI is told "Write new notes linked from 'Pilzsuche' in German (de)",
and a note made with *Save as new node* gets ~#+language: de~.

Edits keep a note's language: the AI does not translate unless I ask,
and it does not add or change ~#+language:~ unless I ask. Notes written
by hand get no ~#+language:~.

To set the language of existing notes:
1. In *Search*, long press a result to select it, and tap more notes.
2. Tap *Set language…* and enter a code such as ~de~.
3. One *Undo* in the message restores all files. See
   [[id:roam-graph-help-search][Search and selected notes]].

* Copy an error
:PROPERTIES:
:ID:       roam-graph-help-copy-error
:END:
Errors in *Create image*, the chat, *Edit with AI* and the change set
screen have a copy icon (*Copy error*), and the text can be selected. An
error in a snack bar has a *Copy* action and stays until it is dismissed.
Paste the copied text when you report a problem.

The copied text has the message, the app version, the platform, the time
(UTC) and, for AI errors, the provider, the model, the API kind, the HTTP
status and the provider's own answer under "Answer:" (cut to 2000
characters). It has no keys or tokens.
